# Atividade

1. Crie um projeto web criativo utilizando npm + react + tailwind;

```bash
    npm create vite
    cd nome_do_projeto
    npm install
```

2. Editar o arquivo app.tsx e coloque/crie um jogo qualquer;

3. Lançar uma instância e instale o **docker** no EC2 AWS.

4. Conteinizar o seu jogo e executá-lo em um conteiner docker;

5. Teste o seu jogo conteinizado!;
